# NREL 5 MW 旋转叶片结构幅频响应

在 MATLAB 中先运行 COCO 的 `startup`，再从 QuasiP 根目录运行以下命令。

```matlab
install
cd example/windTurbine
direction = 'edge';   % 'flap'、'edge' 或 'torsion'
amplitude = 20;       % 沿参考弧长均布的谐波载荷峰值，单位见下表
speed = 12.1;         % 轮毂转速，rpm；省略时取 12.1
frc = run_blade_frc(5,direction,amplitude,speed);
check_blade_orbit(5,'peak',256,direction,amplitude,speed)
```

只改 `direction` 即可切换工况。第一个参数为谐波阶数；省略方向时默认 `flap`，省略幅值时三个方向均取数值 60。`run_blade_frc(5)` 和原来的 flap 算例相同。CSV、PNG 和可编辑的 MATLAB FIG 保存于本目录，COCO 检查点位于 `data/<运行名>`。文件名区分方向、转速、幅值和谐波阶数，默认幅值 60 沿用省略幅值标记的命名。

| 方向 | 沿参考弧长施加的激励 | 叶尖输出（相对离心平衡构型） | 扫频中心 |
|---|---|---|---|
| flap | 旋转系第 3 方向力，N/m | 第 3 平移分量，m | 第 1 阶 |
| edge | 旋转系第 2 方向力，N/m | 第 2 平移分量，m | 第 2 阶 |
| torsion | 绕当前截面局部展向轴的分布力矩，N·m/m | 叶尖相对姿态绕平衡截面展向轴的扭转角，deg | 第 6 阶 |

扭转角从相对四元数作 swing–twist 分解得到，采用 ±180° 的主值。三个方向均对物理输出取周期内的最大绝对值。

## 结构与载荷

17 个三节点 GEF 单元使用与 `windTurbineBladeModal_rotFrame_quat.m` 相同的 35 站截面数据和展向预扭。2.5° 预锥角同时作用于参考节点位置和姿态。根部固定到初始位姿，轮毂绕旋转系第 3 轴以指定转速恒速转动。重力、气动力均取零。频段为当前转速下所选模态线性角频率的 0.95–1.05 倍。

## 阻尼与周期解

在无周期载荷的离心平衡点，先计算约束切空间上的质量和切线刚度。用质量归一化模态构造经典模态阻尼矩阵，每个弹性模态的目标阻尼比为 0.0048。该矩阵在一次延拓中固定。程序将陀螺矩阵计入线性化极点，并打印实测阻尼比范围。

QuasiP 的 MP/mVCF 谐波平衡求解全部 245 个位置与四元数分量，以及各自的速度、加速度和 41 个约束乘子。求解变量按离心平衡态平移和缩放。物理坐标通过模型的 `scale`、`q` 和 `lm` 恢复。约束切空间用于线性模态分析，非线性延拓保留全部坐标。稳定性判别关闭。

`blade_force.m` 批量计算 GEF 单元在参考弧长上的弹性力、构形相关惯性力和恒速旋转项。单元雅可比通过复步微分获得。每次建模都会在扰动状态下与 GEF 原生装配器交叉核对力向量。`check_blade_orbit` 从 HB 波形的初值出发，对同一受约束方程作一个激励周期的 Newmark 时域积分，报告叶尖幅值、波形误差和周期闭合误差。
